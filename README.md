# 🦖 DinoPedia

Una página web temática inspirada en dinosaurios y el universo de Jurassic Park, desarrollada con HTML, CSS y JavaScript.

El proyecto muestra una colección de tarjetas personalizadas estilo Funko Pop de integrantes del equipo, cada una con información, descripción, precio y stock disponible.

---

## ✨ Características

- 🎠 Carrusel interactivo con imágenes y memes.
- 🔍 Buscador dinámico en tiempo real.
- 🃏 Tarjetas generadas automáticamente desde una base de datos en JavaScript.
- 📱 Diseño moderno y responsive.
- 🗺️ Integración de Google Maps.
- 🎨 Estilo visual inspirado en dinosaurios y Jurassic Park.

---

## 🛠️ Tecnologías utilizadas

- HTML: FrontEnd, Estructura.
- CSS: FrontEnd, Diseño.
- JavaScript: BackEnd, Lógica.
- Bootstrap: Framework.
